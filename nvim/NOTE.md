# Neovim

**Dependencies:** Neovim 0.12+, Git, tree-sitter-cli 0.26.1+, C compiler, make, curl, tar, unzip, gzip, rg. For C/C++: clangd and clang-format. Optional: fd, Nerd Font.

**Useful commands:**

- :TSInstallConfigured — install configured Tree-sitter parsers.
- :TSUpdate — update parsers after a Tree-sitter plugin update.
- :MasonInstall stylua lua-language-server pyright rust-analyzer — install the Lua formatter and LSP servers.
- :LspInfo / :ConformInfo — check LSP attachment / formatter availability.
